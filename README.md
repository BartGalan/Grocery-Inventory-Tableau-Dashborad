# Grocery Inventory Report – Tableau Desktop Dashboard

## Introduction

This dashboard presents the  Grocery Inventory report, sales dataset inventory and sales data for Grocery Store Management provided by Willian Oliveira Kaggle (https://www.kaggle.com/datasets/willianoliveiragibin/grocery-inventory). It enables users to analyze how the company sale and inventory performance look like through the year, focusing on key performance indicators (KPIs).

The dataset excel file from the Kaggle has been imported into Tableau and some of visualizations are powered by calculated fields.

## Dashboard Structure

First page of dashboard (Overview) includes KPIs: Total Sale by Unit Price, Total Sale Volume and Average Sale Volume, and 4 visualizations which shows sale in varius perspectives (products, suppliers, category, time).   

The second page includes KPIs: Average Storage Duration, Products Below Reorder, Avergae Inventory Turnover Rate and 2 visualizations: Storage Duration. For both visualizations there is a filter panel with categories, inventory status, threshold level and storage duration range.

## Summary

This project can be used to analyze key account KPIs and support inventory management. Based on the presented data, users can better understand flows of products and their impact in sale. The dashboard also serves as a visually engaging way to present insights to stakeholders.
